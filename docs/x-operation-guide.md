# カブノオト X(Twitter) 運用ガイド

> 作成日: 2026-03-27
> ステータス: ステップ1 実行中

## プロフィール設定

- **名前:** ao@カブノオト
- **自己紹介:**

```
フリーランスエンジニアで個人投資家
「自分がほしい投資ツール」を作ったら止まらなくなった人
Next.js / 日本株 / 投資メモ / 個人開発
カブノオト🗒️というアプリを作ってます
```

- **リンク:** カブノオトのURL

## 運用目的

**需要検証ファースト。** フォロワー数ではなく「10人のヘビーユーザー」が目標。
Xは「発信場所」ではなく「投資家と出会う場所」として使う。

## 3ステップ戦略

### ステップ1: 人格づくり（1-2週間）← 今ここ

目的: 「投資について考えている、まともな人間」だと示す

- 自分のタイムラインに投資の考えや開発の話を投稿する
- プロフィールに「個人投資家 / カブノオトという投資管理ツールを開発中」と書く
- この段階では誰にも話しかけない。ただ「中身のあるアカウント」を作る
- 週3-5本ペース

### ステップ2: 自然な交流（2-3週目）

目的: #株クラ コミュニティに自然に溶け込む

- 共感するポストにいいね・引用RT
- 「自分もそれ困ってます」程度の自然なリプライ
- **絶対にやらない:** 「カブノオトで解決できますよ！」的な営業

### ステップ3: 需要検証（4週目以降）

目的: 実際に使ってもらい、フィードバックを得る

- 「投資の管理どうしてますか？」という会話の流れで自然に紹介
- DMで「よかったら使ってみてもらえませんか？」
- フィードバックを丁寧に拾い、プロダクト改善に活かす

## ステップ1 投稿ドラフト（10本）

### 1. 質問系（交流のきっかけ）

```
皆さん株の管理ツール？？とかってどういうものを使っているんでしょうか。
証券会社のアプリとかが主なんでしょうか？？
参考にさせてください！！
```

### 2. 証券アプリへの不満（共感系）

```
証券会社のアプリ、売買はできるけど
「考える」ための機能が全然ないの自分だけ？

・この銘柄なんで買ったんだっけ
・決算いつだっけ、全銘柄まとめて見たい
・損切りライン決めたけどどこにメモしたっけ

情報がバラバラすぎて
結局スプレッドシートに戻るやつ…
```

### 3. 決算シーズンネタ（時事性）

```
決算シーズン近づいてきたけど、
保有銘柄の決算日ちゃんと把握してますか？

自分は以前、決算日を見落として
持ち越してしまい痛い目に遭いました…

それ以来、カレンダーにまとめて
「持ち続けるか減らすか」を事前に決めるようにしてます。
事前に決めておくだけでストレスが全然違う。
```

### 4. 損切りの考え方

```
「見切り千両」

頭では分かってる。でも含み損のまま持ち続けちゃう。

自分なりの対策は、買う「前」に
「ここまで下がったら売る」を書き出しておくこと。

含み損を見てからだと感情で判断しちゃうけど、
冷静な時の自分が決めたルールなら従える。

これだけで損切りの精度がかなり変わりました。
```

### 5. 開発ストーリー（個人開発の共感）

```
証券アプリの使いづらさにモヤモヤして
「自分が欲しい投資ツール」を作り始めたら
止まらなくなりました。

最初は銘柄メモだけのつもりが…
配当カレンダー→決算管理→ポートフォリオ分析→
ゲーミフィケーション→ブログまで。

自分が使いたいものを作るの、楽しすぎる。

#個人開発
```

### 6. 投資格言シリーズ

```
好きな投資格言。

「休むも相場」

焦って取引しそうな時にこの言葉を思い出す。
ポジション持ってない時のほうが
冷静に銘柄研究できるんですよね。

何もしないことが最善の判断になる日もある。

皆さんの好きな格言あったら教えてください。
```

### 7. スイングトレードの話（投資スタイル）

```
自分の投資スタイルはスイング〜長期。
デイトレみたいにチャートに張り付けないので
本業と両立しやすいのが気に入ってます。

ただこのスタイルだと
「なぜ買ったか」「次にどうするか」の
思考整理が超大事になる。

数週間〜数ヶ月の間に
当時の判断を忘れちゃうんですよね…
```

### 8. 証券アプリでできないこと（具体例）

```
証券アプリに欲しいけどない機能、
自分の場合はこのあたり。

・銘柄ごとに「次やること」をメモしたい
・損切り/利確ラインを一覧で管理したい
・決算日を全銘柄まとめて確認したい
・配当がいつ・いくら入るかカレンダーで見たい

同じこと思ってる人いませんか？
```

### 9. 投資日記のすすめ

```
投資日記、つけてますか？

大げさなものじゃなくて
「今日の市場で気になったこと」を一行書くだけ。

3ヶ月続けると自分の判断パターンが見えてくる。

「自分は〇〇の時に焦って買いがち」とか
「△△業界のニュースに過剰反応しがち」とか。

自分を知ることが投資で一番の武器だと思う。
```

### 10. バイブコーディングの話（開発者向け）

```
エンジニアで投資やってる人、意外と多いですよね。

自分はClaude Codeを使って
投資メモアプリをバイブコーディングで作ってます。

「銘柄ごとにメモ書けるやつ作って」から始まって
気づいたら2ヶ月で25機能以上に…

技術記事はZennに書いてるので
興味ある方はプロフィールからどうぞ。

#個人開発 #バイブコーディング
```

## 投稿のルール

- 宣伝しない。カブノオトのURLは貼らない（ステップ1では）
- 1日1本まで。投稿時間は平日7:00-8:00 or 21:00-22:00（投資家のアクティブ時間）
- ハッシュタグは1-2個まで。多すぎると業者っぽくなる
- 画像やスクショがあると engagement 2-3倍

## やらないこと

- フォロワー数を気にする
- いいねが少なくても気にしない
- 他のアカウントの真似をしない
- カブノオトの宣伝を直接しない（ステップ1-2では）
