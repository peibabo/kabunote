## 成長投資枠で個別株を買うメリット

新NISAの成長投資枠は、年間240万円まで個別株を非課税で運用できる制度です。投資信託だけでなく**個別株を組み入れる**ことで、配当金の非課税メリットを最大限に活かせます。

### 非課税の効果はどれくらい？

具体的な数字で確認してみましょう。配当利回り3.5%の銘柄を成長投資枠で240万円分保有した場合を例にとります。

| 項目 | 特定口座 | NISA口座 | 差額 |
|------|---------|---------|------|
| 年間配当金（税引前） | 84,000円 | 84,000円 | — |
| 税金（約20.315%） | 17,065円 | 0円 | — |
| 手取り配当金 | 66,935円 | 84,000円 | **+17,065円** |
| 10年間の手取り合計 | 669,350円 | 840,000円 | **+170,650円** |

10年間で約17万円の差が出ます。これは「何もしなくても得られる差額」であり、配当利回りが高い銘柄ほど、また保有期間が長いほど効果は大きくなります。

### 売却益も非課税になる

配当だけでなく、**値上がり益（キャピタルゲイン）も非課税**です。たとえば240万円で購入した銘柄が360万円になって売却した場合、特定口座なら約24万円の税金がかかりますが、NISA口座ならゼロ。この差は無視できません。

さらに新NISAでは、売却すると翌年にその分の非課税枠が復活します。つまり、成長した銘柄を売却して別の銘柄に入れ替えるという運用も可能です。

## 成長投資枠に向いている銘柄の3タイプ

では、成長投資枠にはどんな銘柄を入れるべきでしょうか。**非課税メリットを最大化する**という観点から、3つのタイプに分けて考えます。

### タイプ1: 安定高配当型

| 特徴 | 詳細 |
|------|------|
| 配当利回り | 3.5%以上 |
| 業種の傾向 | 通信、銀行、商社、電力 |
| メリット | 毎年の非課税効果が大きい |
| 注意点 | 減配リスクを確認する |

配当利回りが高い銘柄は、NISA口座に入れることで毎年の非課税効果が最も大きくなります。**10年以上の長期保有を前提に、安定して配当を出し続けている企業**を選びましょう。

選定のチェックポイント:

- 過去10年間で減配がない（または1回以下）
- 配当性向が50%以下（無理な配当ではない）
- 営業利益率が安定している
- 自己資本比率が40%以上

### タイプ2: 連続増配型

| 特徴 | 詳細 |
|------|------|
| 配当利回り | 2.0〜3.5%（現時点） |
| 業種の傾向 | 食品、日用品、リース、IT |
| メリット | 将来の配当利回りが上昇する |
| 注意点 | 成長鈍化で増配が止まるリスク |

現時点の利回りはそこそこでも、**毎年増配を続けている企業**は長期的に非課税メリットが拡大していきます。

たとえば、現在の配当利回りが2.5%でも、毎年5%ずつ増配する企業なら、10年後の実質利回り（取得価格ベース）は約4.1%に達します。しかもその配当金はすべて非課税です。

### タイプ3: 成長+配当バランス型

| 特徴 | 詳細 |
|------|------|
| 配当利回り | 1.5〜2.5% |
| 業種の傾向 | 半導体、医薬品、SaaS |
| メリット | 値上がり益と配当の両方が非課税 |
| 注意点 | 株価の変動幅が大きい |

成長性が高く、かつ配当も出している企業をNISA枠に入れるパターンです。**値上がり益が非課税になるメリット**が特に大きいため、成長に確信が持てる銘柄にはこのタイプが有効です。

### 3タイプの使い分け

| 投資家のタイプ | おすすめの配分 |
|-------------|-------------|
| 安定重視（退職後・保守的） | 安定高配当型 70% + 連続増配型 30% |
| バランス型（30〜50代） | 連続増配型 40% + 安定高配当型 30% + 成長型 30% |
| 成長重視（20〜30代） | 成長型 50% + 連続増配型 30% + 安定高配当型 20% |

## NISA枠と特定口座の銘柄振り分け

成長投資枠は年間240万円、生涯で1,200万円が上限です。すべての銘柄をNISAに入れられるわけではないため、**どの銘柄をNISAに入れ、どの銘柄を特定口座にするか**の判断が重要になります。

### 振り分けの判断フレームワーク

以下の条件に当てはまる銘柄ほど、NISA枠に入れる優先度が高くなります。

| 優先度 | 条件 | 理由 |
|--------|------|------|
| 高 | 長期保有する確信がある | 非課税期間を最大限活かせる |
| 高 | 配当利回りが高い | 毎年の非課税効果が大きい |
| 高 | 値上がりが期待できる | 売却益の非課税メリットが大きい |
| 中 | 増配傾向がある | 将来の非課税効果が拡大する |
| 低 | 短期売買の可能性がある | 枠の消費が早く効率が悪い |
| 低 | 損切りの可能性がある | NISAでは損益通算ができない |

### NISAに入れるべきでない銘柄

NISA口座の最大の注意点は、**損失が出ても他の口座と損益通算ができない**ことです。

特定口座で100万円の利益、別の特定口座で50万円の損失が出た場合、確定申告で相殺して50万円分の税金だけ払えばよいのですが、NISA口座の損失はこの計算に含められません。

したがって、以下のような銘柄は特定口座で保有する方が合理的です。

- 業績のブレが大きく、損切りの可能性がある銘柄
- 短期的なトレードを想定している銘柄
- 株価が割高で調整リスクがある銘柄

## NISA個別株ポートフォリオの管理方法

NISA枠で個別株を運用するなら、通常の株式投資以上に**計画的な管理**が求められます。

### 1. 枠の消費状況を把握する

年間240万円の枠は、使い切ったら翌年まで追加購入ができません。**今年の残枠がいくらあるか**を常に把握しておくことが大切です。

管理のポイント:

- 年初に年間の購入計画を立てる（例: 毎月20万円ずつ、ボーナス月に追加）
- 購入のたびに残枠を記録する
- 急落時の買い増し余力を残しておく（枠の20〜30%は予備として確保）

### 2. NISA銘柄と特定口座銘柄を区別して管理する

同じ銘柄をNISA口座と特定口座の両方で保有することもあります。このとき、**口座ごとの損益を分けて把握する**ことが重要です。

| 管理項目 | 確認頻度 | ポイント |
|---------|---------|---------|
| NISA枠の損益 | 週1回 | 含み損銘柄の理由を再確認 |
| 特定口座の損益 | 週1回 | 年末の損益通算を意識 |
| 配当金の受取状況 | 四半期ごと | NISA分は非課税か確認 |
| 枠の残り | 購入時 | 年間計画との差異を確認 |

### 3. 出口戦略を考えておく

NISAは非課税だからといって、永遠に持ち続ける必要はありません。以下のタイミングで売却を検討しましょう。

- **投資仮説が崩れたとき** — 買った理由がなくなったら、非課税であっても売却を検討
- **枠を入れ替えたいとき** — より魅力的な銘柄が見つかったら、売却して翌年の復活枠で購入
- **目標株価に到達したとき** — 事前に決めた目標に達したら、利益確定して次の銘柄へ

## よくある失敗と対策

### 失敗1: 枠を使い切ることが目的化する

「240万円の枠を余らせるのはもったいない」と焦って、十分な分析をせずに銘柄を購入してしまうケースです。

**対策**: 枠を使い切ることよりも、**良い銘柄を適切な価格で買うこと**が大切です。余った枠は翌年に持ち越せませんが、無理に使うよりも現金で持っている方がはるかにマシです。

### 失敗2: NISAだから損切りしない

「NISAは長期保有のためのもの」と思い込み、投資仮説が崩れた銘柄をいつまでも持ち続けるケースです。

**対策**: NISAでも損切りの基準は同じです。**買った理由がなくなったら売る**というルールは、口座の種類に関係なく適用しましょう。ただし、損益通算ができないことを踏まえ、購入時点でより慎重に銘柄を選ぶことが大切です。

### 失敗3: 短期売買で枠を浪費する

値動きの激しい銘柄で短期売買を繰り返すと、あっという間に年間枠を消費してしまいます。売却枠が復活するのは翌年のため、年内の再購入には枠が足りなくなります。

**対策**: 成長投資枠は**長期保有を前提とした銘柄に使う**のが基本です。短期トレードは特定口座で行いましょう。

### 失敗4: 配当金の受取方式を間違える

NISA口座で配当金を非課税にするには、**「株式数比例配分方式」**を選択する必要があります。「登録配当金受領口座方式」や「配当金領収証方式」を選んでいると、NISA口座の銘柄であっても配当金に課税されてしまいます。

**対策**: 証券会社の設定画面で、配当金受取方式が「株式数比例配分方式」になっているか確認しましょう。

## まとめ

新NISAの成長投資枠は、個別株投資家にとって強力な非課税制度です。

- **高配当株・連続増配株・成長株**の3タイプから、自分のスタイルに合った銘柄を選ぶ
- **損益通算ができない**ため、損切りリスクの低い銘柄を優先してNISA枠に入れる
- 枠の消費状況と口座ごとの損益を**分けて管理する**
- 配当金の受取方式は**「株式数比例配分方式」**を選択する
- 枠を使い切ることよりも、**良い銘柄を適切な価格で買う**ことを優先する

NISA口座と特定口座の制度の違いについては、「[NISA口座と特定口座の違いとは？](/blog/nisa-vs-tokutei-account)」で詳しく解説しています。高配当株の選び方は「[高配当株の選び方](/blog/how-to-choose-high-dividend-stocks)」も参考にしてください。
