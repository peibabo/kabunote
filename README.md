# カブノオト - 投資思考整理ダッシュボード

![Kabunote Logo](public/kabunote-logo.png)

> 投資家の思考を整理する、直感的で美しいダッシュボード

## 🎯 概要

**カブノオト**は、投資家のための思考整理に特化したWebアプリケーションです。日本株投資において、銘柄の分析・メモ・ポジション管理を一元化し、より良い投資判断をサポートします。

### ✨ 主な特徴

- 📝 **株ノオト機能** - 銘柄別の詳細メモ管理
- 🏷️ **カスタムタグ** - 視覚的な銘柄分類
- ✋ **ドラッグ&ドロップ** - 直感的な並び替え
- 💼 **ポジション管理** - 複数建玉の詳細追跡
- 🎯 **投資規律設定** - 目標・損切りラインの管理
- 🔍 **全銘柄検索** - 高速・高精度な検索機能

## 🚀 クイックスタート

### 必要環境

- Node.js 18.0+
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/peibabo/kabunote.git
cd kabunote

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

### アクセス

ブラウザで [http://localhost:3000](http://localhost:3000) を開く

## 🎨 機能紹介

### 1. 銘柄管理
- **検索機能**: 会社名・銘柄コードでの高速検索
- **オートコンプリート**: リアルタイム検索サジェスト
- **CSV データベース**: 日本株全銘柄データを内蔵

### 2. 株ノオト
- **モーダル編集**: 大画面での編集モード
- **自動保存**: リアルタイムでのデータ保存
- **永続化**: ブラウザ再起動でも内容を保持

### 3. ドラッグ&ドロップ
- **直感的操作**: ドラッグハンドルでカード移動
- **視覚的フィードバック**: 美しいアニメーション効果
- **順序記憶**: 並び順を自動保存

### 4. ポジション管理
- **複数ポジション**: 同一銘柄の分割建玉管理
- **自動計算**: 平均取得価額・総投資額の算出
- **詳細記録**: 取得日・メモ等の詳細情報

### 5. 投資規律
- **目標設定**: 利益確定ラインの設定
- **リスク管理**: 損切りラインの明確化
- **進捗可視化**: ゲージによる進捗表示

## 🛠️ 技術スタック

- **Frontend**: Next.js 16.1.6 + TypeScript
- **Styling**: Tailwind CSS
- **ドラッグ&ドロップ**: @dnd-kit
- **データ**: CSV + localStorage
- **フォント**: M PLUS 1p, Google Fonts

## 📂 プロジェクト構造

```
src/

│   └── FavoriteGroupManager.tsx # グループ管理
```

## 🎯 使用方法

### 1. 銘柄を追加
1. 検索ボックスに銘柄コードまたは会社名を入力
2. オートコンプリートから選択またはEnterキーで追加

### 2. 株ノオトを編集
1. カード内のテキストエリアで直接編集
2. 「株ノオトを大きく開く」ボタンでモーダル編集

### 3. カードを並び替え
1. カード右上の「⋮⋮」ハンドルをドラッグ
2. 好きな位置にドロップして並び替え

### 4. ポジションを管理
1. 「ポジション管理」ボタンをクリック
2. 株数・取得価額・日付を入力して記録
